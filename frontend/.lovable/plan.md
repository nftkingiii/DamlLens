You have two ways to export your current codebase:

## Option 1: Download as ZIP (fastest, paid workspaces)

Desktop:

1. Open the Code Editor (code icon above the preview)
2. Scroll to the bottom of the file tree on the left
3. Click **Download codebase**

This gives you a ZIP of the entire project — no GitHub account needed.

## Option 2: Connect GitHub (recommended for ongoing work)

Desktop:

1. In the chat input, click the **+** (plus) menu → **GitHub** → **Connect project**
2. Authorize the Lovable GitHub App and pick the account/organization
3. Click **Create Repository** — Lovable pushes your code and keeps it in two-way sync
4. From your new GitHub repo, use **Code → Download ZIP** or `git clone <repo-url>`

Mobile: Chat mode → **+** → **GitHub**.

## Notes

- Database data is exported separately: **Cloud → Advanced settings → Export data**.
- Once on GitHub, you can self-host anywhere (the code is standard TanStack Start + Vite).
